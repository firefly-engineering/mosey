mosey delegation signing spike

Open in a browser with Phantom / Solflare / Backpack installed. This renders the exact canonical delegation text, signs it with signMessage, and prints a JSON blob. Pipe that blob into the Go verifier: 

  pbpaste | go run verify.go      # or save to wallet.json: go run verify.go < wallet.json

If the verifier prints PASS … verifies over the raw UTF-8 content, the wallet signs the raw bytes (no envelope) and open question #2 is closed. If it FAILs, the wallet wrapped the bytes (e.g. Solana's \xffsolana offchain framing) and we must match that framing server-side.
